# Price Tracker Client

Vanilla JS SPA for the Price Tracker API.

## Docker installation

```shell
# Clone the repository. You can use https, if you don't intend to push changes.
git clone git@github.com:kulpsin/pwp_pricetracker.git
cd pwp_pricetracker

# Optional: if running API at specific host, configure it in .env
echo 'API_BASE_URL="https://api.example.net"' >> .env

# Build the docker image
docker compose build client

# Set the port you want to serve the client from
echo "CLIENT_PORT=8001" >> .env

# Start the docker container in detached mode
docker compose up -d client

# Test that you can send requests to the client server
curl -s --head 'http://127.0.0.1:8001'
```
